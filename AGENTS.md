# Agent Rules

You may run these commands without asking:

- git status
- git diff
- git log
- git checkout -b
- git commit
- git push
- composer install --no-interaction
- composer update --no-interaction
- npm install
- npm run build
- php artisan migrate --force (local only)
- php artisan test
- vendor/bin/pest
- phpunit
- cat, ls, find, grep, rg

Do NOT run without asking:
- rm -rf
- dropping databases
- force push
- deleting branches
- modifying production configs

Always:
- keep changes scoped
- run tests after changes
- commit and push after completing tasks
